# Playwright

## Что это
Современный инструмент для автоматизации браузеров (альтернатива Selenium).

## Преимущества
- Быстрее и стабильнее Selenium
- Встроенные ожидания (не нужны WebDriverWait)
- Поддерживает Chromium, Firefox, WebKit
- Умеет работать в headless-режиме из коробки
- Отлично подходит для e2e-тестов

## Установка
```bash
pip install playwright
playwright install
