# JavaScript для QA

## Переменные
- let — изменяемая переменная
- const — константа (нельзя переопределить, но свойства объекта менять можно)
- var — устаревший способ

## Типы данных
- number, string, boolean, null, undefined, object, array
- Массив: [1, 2, 3]
- Объект: {name: "Андрей", role: "QA"}
