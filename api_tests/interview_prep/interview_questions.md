## Python

### 1. Список и словарь
- Список — упорядоченная последовательность, доступ по индексу.
- Словарь — пары «ключ-значение», доступ по ключу.
- Список — для перебора и порядка, словарь — для быстрого поиска по ключу.

### 3. Исключения
- Исключение — ошибка во время выполнения.
- Обрабатываю через try/except, чтобы программа не падала.

### 4. Модуль requests
- Библиотека для HTTP-запросов.
- Тестирование REST API (GET, POST, PUT, DELETE), проверка статус-кодов, JSON.

### 5. pytest
- Фреймворк для тестирования.
- Фикстуры — подготовка окружения (драйвер, клиент, БД).

## SQL

### 1. JOIN
- Соединение таблиц.
- INNER JOIN — только совпадающие.
- LEFT JOIN — все из левой, NULL при отсутствии.
- SELF JOIN — таблица сама с собой (дубликаты).

### 2. GROUP BY и HAVING
- GROUP BY — группирует строки.
- HAVING — фильтрует группы после агрегации.
- Пример: SELECT user_id, SUM(amount) FROM orders GROUP BY user_id HAVING SUM(amount) > 500;

### 3. WHERE и HAVING
- WHERE — до группировки.
- HAVING — после группировки, по агрегатам.

### 4. Подзапрос
- Запрос внутри другого.
- Пример: SELECT name FROM users WHERE id IN (SELECT user_id FROM orders WHERE amount > (SELECT AVG(amount) FROM orders));
